# scoolhackas

An ultra-minimalist, premium, gamified SaaS application platform built using **React**, **Tailwind CSS**, and **shadcn/ui**. Featuring structured account management, dynamic XP progression, a custom task/quest framework, and a native tab-cloaking disguise engine.

---

## ✨ Features

### 🎮 Gamified Rank & Level-Up Engine
A global state-tracking machine that manages level thresholds and experience points (XP) natively via persistent local storage profile boundaries. Standard navigation permissions are strictly gated behind 6 distinct operational tiers:
- **beginner hacka** (Levels 1-5): Foundation layout profile access.
- **intermediate hacka** (Levels 6-12): Core utility and cloak layout structures.
- **pro hacka** (Levels 13-20): Advanced script modules and initial proxy channels.
- **alpha hacka** (Levels 21-30): Comprehensive tasking and custom gaming engines.
- **omega hacka** (Levels 31-45): Complete platform access mechanics.
- **the hacka** (Levels 46+): Unrestricted root-level access and owner messaging pathways.

### ⏱️ Interactive Quest Dashboard
A core system built straight into the user's home screen that handles task management, progression updates, and live event loops:
- Automated claim tokens for standard operations.
- Synchronized multi-minute countdown timers tracking complex background operations with interactive completion steps.

### 🕶️ Google Tab Cloak Engine
A client-side utility switch built into the profile manager that instantly intercepts browser metadata for ultimate privacy:
- Switches DOM header text dynamically to standard browser configurations (`document.title = "Google"`).
- Replaces runtime layout favicons with secure, official external lookups.

### ⚙️ Architecture Design
- **Clean Submenus:** The "hacks", "proxy", and "other hacka stuff" pages are kept as clean, empty panel skeletons with absolute zero AI bloat, giving the developer complete control to map live links natively.
- **Responsive Layout:** Optimized entirely for desktop screens, fluid micro-interactions, custom brand coloring, and full multi-theme toggle configurations.

## 🚀 Getting Started

### Local Development Setup

Ensure you have [Node.js](https://nodejs.org) and [pnpm](https://pnpm.io) installed locally:

```bash
# 1. Clone the repository
git clone https://github.com

# 2. Navigate to project root
cd scoolhackas

# 3. Install core dependencies
pnpm install

# 4. Launch the local development server
pnpm dev
```
